# 第 10 章：趋势与延伸

> **本章导读**｜预计 10 分钟
>
> 最后一章把视角拉高：沙箱不只是「安全组件」，它正在变成 **Agent 时代的操作系统与基础设施原语**。
> 这一章给方向，不给答案——因为这里变化最快。

## 10.1 五个趋势

| # | 趋势 | 含义 |
|---|---|---|
| 1 | **基础设施原语** | 沙箱正变成 Agent 基础设施的「数据库级」原语：就像后端离不开数据库，Agent 离不开执行环境 |
| 2 | **快照 / 分叉** | 用于并行探索和 RL 训练（同状态复制多份跑不同分支） |
| 3 | **从跑代码到操作电脑** | 带 GUI 的完整 VM（computer-use），Agent 像人一样点鼠标、看屏幕 |
| 4 | **MCP 标准化** | 沙箱接入越来越标准化、可替换，降低锁定 |
| 5 | **安全重心转移** | 从「防逃逸」转向「**防数据外泄 + 供应链 + 成本控制**」 |

## 10.2 延伸地图

把沙箱看成「Agent 的计算机 / 操作系统」，延伸面会打开：

```
                    仿真 / 具身 / 数字孪生
                            ▲
            多沙箱编排 ─────┤───── 训练环境 (RL/rollout)
                            │
   本地/边缘 ◄───  [ Agent 沙箱 ]  ───► 协议 / 市场 / 计费
                            │
        TEE / 可验证 ───────┼────── 数据沙箱 / 隐私计算
                            ▼
                    合规 / 责任 / 治理
```

## 10.3 八条延伸轴

| 轴 | 从 → 到 | 关键点 |
|---|---|---|
| 时间轴 | 一次性 → 有状态 → 可训练 | 长驻工作区、快照分叉做 RL rollout |
| 空间轴 | 单沙箱 → 多沙箱 → 仿真世界 | 多 Agent 协作、数字孪生 |
| 能力轴 | 跑代码 → 操作整台电脑 | computer-use、工具自造 |
| 信任轴 | 隔离 → 可验证 → 可追责 | TEE、审计、合规 |
| 数据轴 | 计算隔离 → 数据隔离 | 隐私计算、联邦学习、洁净室 |
| 边界轴 | 云端 → 边缘 / 本地 | WASM 端侧、本地 Agent 运行时 |
| 生态轴 | 工具 → 协议 → 市场 | MCP 标准化、环境 / 应用市场 |
| 治理轴 | 被动沙箱 → 主动监管 | 策略引擎、熔断、human-in-the-loop |

## 10.4 最有价值的四个方向

1. **训练环境**（快照 / 分叉 → RL、自我改进）
2. **Computer-use**（操作完整电脑 → 虚拟员工）
3. **可信与可验证**（TEE + 审计 → 合规落地）
4. **多沙箱协作**（多 Agent 社会 / 仿真）

## 10.6 核心判断

> 沙箱正在从「安全组件」演化成 **Agent 时代的操作系统与基础设施原语**。
> 今天把它当「要不要加个安全层」来讨论，就像 2000 年代讨论「要不要用数据库」——几年后会变成默认前提。
