很多人第一次听到「沙箱」，会以为它是**给不可信代码准备的牢房**。这对传统安全成立，但对 Agent **只说对了一半**。

> **Agent 沙箱 = Agent 的计算机。**
> 它既是「牢房」，也是 Agent 的「手和脚」。

- 没有沙箱，LLM 只能**说**，不能**做**。
- 有了沙箱，LLM 才能改文件、跑脚本、装依赖、发请求，真正产生副作用。

所以理解 Agent 沙箱，要同时抓住两个词：

| 词 | 含义 |
|---|---|
| **赋能** | 给 Agent 一个能干活的环境 |
| **约束** | 让它在受控范围内干活，闯不了祸 |

## 一个直观的类比

把 LLM 想象成一个**很聪明但没有手的人**：

- 他只能动嘴（输出文本）。
- 你想让他帮你改电脑上的文件、跑个脚本，他做不到。
- 沙箱就是给他配的一台**一次性电脑**：他能上去操作，但搞坏了也伤不到你的主机。

## 本章要点

1. 沙箱对 Agent 是**赋能工具**，不只是安全组件。
2. 它同时承担「能干活」和「闯不了祸」两个职责。
3. 后面所有章节，都是围绕这两个职责展开的。
